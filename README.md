# Robert's Obsidian Plugins

Plugins I built for my Obsidian vault. Each folder has the plugin's code and a README.

| | Plugin | What it does |
|:-:|---|---|
| <img src="BetterNotes/logo.svg" width="56" alt="BetterNotes logo"> | **[BetterNotes](BetterNotes)** | Notion-style notes that can hold attachments and sub-notes. |
| <img src="FolderPalette/logo.svg" width="56" alt="FolderPalette logo"> | **[FolderPalette](FolderPalette)** | Folder colors, icons, collapse arrows and tree lines for the file explorer. |
| <img src="ImageGrip/logo.svg" width="56" alt="ImageGrip logo"> | **[ImageGrip](ImageGrip)** | Drag a corner to resize images in Live Preview, and copy them with Ctrl+C. |
| <img src="ReminderSuite/logo.svg" width="56" alt="ReminderSuite logo"> | **[ReminderSuite](ReminderSuite)** | Two-way Google Calendar sync for tasks, with a calendar view and a reminder sidebar. |
| <img src="RobTerminal/logo.svg" width="56" alt="RobTerminal logo"> | **[RobTerminal](RobTerminal)** | A real Windows terminal inside Obsidian, built on ConPTY and xterm.js. |
